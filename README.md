# سامانه متمرکز لینک پرداخت — نسخه آزمایشی

این مخزن یک نمونه اولیه نمایشی برای بررسی تجربه کاربری و گردش کار سامانه متمرکز لینک پرداخت است. درگاه هدف برای فاز عملیاتی، پرداخت الکترونیک سداد (بانک ملی ایران) است؛ اما **این نسخه هیچ اتصال واقعی به سداد یا شبکه بانکی ندارد**.

## اجرای آزمایشی

1. مخزن را باز کنید.
2. از مسیر **Settings → Pages**، بخش **Build and deployment** را روی **Deploy from a branch** قرار دهید.
3. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.
4. پس از تکمیل انتشار، نشانی GitHub Pages در همان بخش نمایش داده می‌شود.

همچنین می‌توانید فایل `index.html` را مستقیماً در مرورگر باز کنید.

## امکانات فعلی

- فرم ایجاد درخواست و لینک پرداخت ساختگی
- نمایش درخواست‌ها و وضعیت آن‌ها در مرورگر فعلی
- شبیه‌سازی موفق، ناموفق و انصراف
- نگهداری داده آزمایشی در localStorage مرورگر

اطلاعات این نسخه فقط در مرورگر همان دستگاه ذخیره می‌شود و پایگاه داده مرکزی ندارد. لینک‌های ساخته‌شده، لینک پرداخت واقعی نیستند.

## معماری موردنیاز برای نسخه عملیاتی

نسخه واقعی باید روی سرور امن (برای مثال VPS ویندوزی) و با یک backend و پایگاه داده پیاده‌سازی شود:

1. احراز هویت سامانه‌های مبدأ و صدور کلید جداگانه برای هر سامانه
2. ایجاد درخواست پرداخت در backend مرکزی و کنترل مبلغ، شناسه یکتا و تکراری نبودن درخواست
3. ثبت رویدادها و وضعیت‌ها در پایگاه داده با کنترل دسترسی
4. ارتباط سرور به سرور با سداد بر اساس مستندات رسمی و اطلاعات پذیرندگی
5. هدایت مرورگر به درگاه رسمی پرداخت
6. اعتبارسنجی نتیجه در سمت سرور از طریق فرایند تأیید/استعلام رسمی سداد؛ صرفاً به پارامترهای برگشتی مرورگر اعتماد نشود
7. اطلاع‌رسانی امن به سامانه مبدأ (webhook) همراه با امضای پیام، شناسه یکتا، کنترل تکرار و امکان retry
8. ثبت گزارش ممیزی، محدودسازی نرخ درخواست، مدیریت خطا و پشتیبان‌گیری

## نکات امنیتی ضروری

- هرگز کلیدها، رمزها، اطلاعات پذیرندگی یا متغیرهای محرمانه را در این مخزن یا کد frontend قرار ندهید.
- GitHub Pages فقط میزبان فایل‌های ایستا است؛ برای نگهداری رازها، فراخوانی امن درگاه یا تأیید قطعی تراکنش مناسب نیست.
- اطلاعات کارت بانکی، CVV2، رمز اول یا رمز پویا نباید در این سامانه دریافت یا ذخیره شوند.
- قبل از توسعه اتصال واقعی، مستندات فنی جاری و قرارداد پذیرندگی سداد باید از مسیر رسمی دریافت و بررسی شوند. نام فیلدها و endpointها در این مخزن عمداً جعل یا حدس زده نشده‌اند.
